💾 오늘 데이터 사용

데이터 불러오기 ⓘ 화면에 정보를 표시하기 위해 데이터베이스에서 가져온 정보의 수예요. 목록을 많이 불러오면 이 숫자가 커질 수 있어요.
서버 조회 요청 ⓘ 데이터베이스에 정보를 요청한 횟수예요. 한 번의 요청으로 여러 정보를 불러올 수도 있어요.

🍮 젤리 관리

👥 전체 젤리 현황

게임을 한 번 이상 완료해 지갑이 만들어진 유저를 잔액순으로 최대 100명 보여줘요.

👤 유저 젤리 조회 · 지급/차감

양수 = 지급, 음수 = 회수. 잔액과 원장(jelly_log)에 함께 기록돼요.

📜 최근 지급·차감 내역 (전체)

서버가 기록한 젤리 원장 최근 30건 — 획득(게임·출석·선물)과 사용(구매·닉변)이 모두 남아요.

💌 친구초대 현황

정상 한 판까지 끝나 양쪽에 +3이 지급된 내역과, 아직 조건을 기다리는 초대를 구분해 보여줘요.
🛡 보안 도구

🛟 점수 누락 복구

오늘 플레이했지만 랭킹에 반영되지 않은 후보를 찾습니다. 자동 복구는 없습니다.
